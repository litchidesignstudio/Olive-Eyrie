# Olive Eyrie homepage concepts

Two independent, responsive homepage directions for Olive Eyrie, a Mediterranean-inspired café in Nagpur.

- [Concept 1: The Slow Escape](theme-one/index.html) — warm stone, olive green and an editorial café mood.
- [Concept 2: The Good Gathering](theme-two/index.html) — berry, peach and bold poster-style typography for food, open mics and celebrations.

Open `index.html` directly in a browser to choose a direction. Each theme is self-contained in its own folder and can also be opened directly. The image and Google Fonts URLs need an internet connection. Update the menu, address and event details to match the café's confirmed information before launch.
